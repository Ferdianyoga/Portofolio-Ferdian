PORTFOLIO FERDIAN YOGA PRATAMA

CARA MENJALANKAN:
1. Buka folder ini di VS Code.
2. Pastikan index.html, style.css, dan script.js berada dalam satu folder.
3. Klik kanan index.html -> Open with Live Server.
4. Website akan terbuka di browser.

MENAMBAHKAN FOTO:
- Foto profil: assets/profile/
- Foto pendidikan: assets/education/
- Foto experience: assets/experience/
- Foto project: assets/projects/
- Sertifikat: assets/certificates/
- CV: assets/cv/

CATATAN:
Versi awal menggunakan placeholder untuk foto agar website langsung berjalan.
Setelah foto dimasukkan, bagian JavaScript dapat disesuaikan agar gambar tampil otomatis.

CV:
Salin file CV terbaru ke:
assets/cv/CV-FERDIAN-YOGA-PRATAMA.pdf
Tombol Download CV sudah diarahkan ke lokasi tersebut.
